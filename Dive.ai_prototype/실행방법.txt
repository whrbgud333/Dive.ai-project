Dive.ai 프로토타입 실행 방법
==============================

사전 준비
---------
아래 네 가지가 먼저 준비되어 있어야 합니다.

  1. Python 설치 (3.11 이상)
     https://www.python.org/downloads/
     설치 후 확인: python --version

  2. Node.js 설치
     https://nodejs.org/
     node --version로 설치 전에 있나 확인 해보시고 없으시면 설치

  3. API 키 및 서비스 계정 준비
     아래 세 가지를 본인 것으로 준비하세요. 각 발급 방법은 맨 아래 [API 발급 방법] 섹션을 참고하세요.

     - OpenAI API 키
     - Google Cloud Vertex AI 서비스 계정 JSON 파일
     - Firebase 프로젝트 설정 (서비스 계정 JSON + 웹앱 config)

  4. vectordb 폴더
     구글 드라이브에서 받은 vectordb 폴더를 Dive.ai_prototype/ 의 상위 폴더
     (즉, Dive.ai/ 바로 아래)에 넣으세요.

     최종 구조:
       Dive.ai/
       ├── vectordb/          ← 여기
       └── Dive.ai_prototype/
               └── .env      ← 여기


---

1단계: Python 패키지 설치
--------------------------
Dive.ai_prototype/ 폴더에서 실행하세요. (처음 한 번만)

  pip install -r requirements.txt


---

2단계: 백엔드 서버 실행 (FastAPI)
-----------------------------------
Dive.ai_prototype/ 폴더에서 실행하세요.

  python main.py

정상 실행 시 http://localhost:8000 에서 대기합니다.
(터미널 창을 닫지 마세요.)


---

3단계: 프론트엔드 실행 (React)
--------------------------------
새 터미널을 열고 아래 순서로 실행하세요.

  cd Dive.ai_prototype/frontend
  npm install       ← 처음 한 번만
  npm run dev

실행 후 브라우저에서 http://localhost:5173 으로 접속하세요.


---

자주 묻는 문제
--------------
Q. 서버가 시작할 때 오류가 나요.
   → .env 파일이 Dive.ai_prototype/ 안에 있는지 확인하세요.

Q. 빌더(시나리오 생성)가 안 돼요.
   → vectordb 폴더 위치를 확인하세요. (Dive.ai/ 바로 아래에 있어야 합니다.)

Q. 프론트엔드 접속이 안 돼요.
   → 백엔드(2단계)가 먼저 실행 중인지 확인하세요.


---

[API 발급 방법]
==============

※ 아래 세 가지를 모두 준비해야 전체 기능을 사용할 수 있습니다.


1. OpenAI API 키
----------------
  1) https://platform.openai.com 접속 후 로그인
  2) 우측 상단 프로필 → API keys → Create new secret key
  3) 발급된 키를 복사하여 Dive.ai_prototype/.env 파일의 아래 항목에 입력

     OPENAI_API_KEY=발급받은키


2. Google Cloud Vertex AI 서비스 계정
--------------------------------------
  Vertex AI를 통해 Gemini 모델(채팅, 시나리오 생성, 이미지 생성 등)이 실행됩니다.

  1) https://console.cloud.google.com 접속 후 새 프로젝트 생성
  2) 좌측 메뉴 → API 및 서비스 → 라이브러리 → "Vertex AI API" 검색 후 사용 설정
  3) IAM 및 관리자 → 서비스 계정 → 서비스 계정 만들기
     - 역할: "Vertex AI 사용자" + "Storage 객체 뷰어" 부여
  4) 생성된 서비스 계정 클릭 → 키 탭 → 키 추가 → JSON 형식으로 다운로드
  5) 다운로드된 JSON 파일을 원하는 경로에 저장 후 .env에 경로 입력

     GOOGLE_APPLICATION_CREDENTIALS=C:\경로\서비스계정.json
     VERTEX_PROJECT=본인프로젝트ID
     VERTEX_LOCATION=us-central1


3. Firebase 설정
----------------
  Firebase는 구글 소셜 로그인(인증)에 사용됩니다.
  백엔드용 서비스 계정 JSON과 프론트엔드용 웹앱 config, 두 가지가 필요합니다.

  [3-1] Firebase 프로젝트 생성 및 Google 로그인 활성화
  1) https://console.firebase.google.com 접속 후 새 프로젝트 생성
  2) 좌측 메뉴 → Authentication → 시작하기 → 로그인 방법 탭
  3) Google 항목 클릭 → 사용 설정 → 저장

  [3-2] 백엔드용 서비스 계정 JSON 발급
  1) Firebase 콘솔 → 프로젝트 설정(톱니바퀴) → 서비스 계정 탭
  2) "새 비공개 키 생성" 클릭 → JSON 파일 다운로드
  3) 다운로드된 파일 경로를 .env에 입력

     FIREBASE_SERVICE_ACCOUNT_PATH=C:\경로\firebase-adminsdk.json

  [3-3] 프론트엔드용 웹앱 config 설정
  1) Firebase 콘솔 → 프로젝트 설정 → 일반 탭 → 하단 "내 앱" 섹션
  2) 웹앱 추가(</> 아이콘) → 앱 등록
  3) firebaseConfig 값 확인 후 frontend/.env 파일을 아래와 같이 교체

     VITE_FIREBASE_API_KEY=값
     VITE_FIREBASE_AUTH_DOMAIN=프로젝트ID.firebaseapp.com
     VITE_FIREBASE_PROJECT_ID=프로젝트ID
     VITE_FIREBASE_STORAGE_BUCKET=프로젝트ID.firebasestorage.app
     VITE_FIREBASE_MESSAGING_SENDER_ID=값
     VITE_FIREBASE_APP_ID=값
